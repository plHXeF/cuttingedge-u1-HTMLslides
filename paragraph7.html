02专业术语①：CNC 负责「做」，CMM 负责「查」

CNC Computer Numerical Control

计算机数控。文中 CNCs = CNC machines，数控机床。
把图纸变成一串数字指令（G 代码），机器照着「切」。

CMM Coordinate Measuring Machine

三坐标测量机。用探针去「摸」零件，读出 X / Y / Z 坐标，判断尺寸合不合格。

Simulator 模拟器

把机床、测量机和整个加工过程搬进电脑：
先在虚拟里「做 → 查 → 改」，确认无误再上真机。

G 代码（数控程序）
本次试错的代价 → 🧱 材料浪费 ¥0 ⏱ 停机时间 0 h ⚙ 设备损坏 ¥0

02专业术语②：模拟 ≠ 数字孪生

simulation 模拟 / 仿真

「如果……会怎样？」
输入假设 → 在虚拟模型里跑一遍 → 看结果。
可以和真实设备没有实时连接。

digital twin 数字孪生

真实设备的「双胞胎」：
传感器数据持续流入 → 虚拟模型同步更新 → 反过来给出预警与优化建议。

一句话：数字孪生 = 会跟着真身一起「长大」的模拟。

value chain
价值链
value chain：每一环都在创造价值（也产生成本与环境影响）｜ life cycle 生命周期：产品从「生」到「死」的过程。本段的 from raw material extraction to end-of-life disposal 就是沿着这条链走一遍。

03核心词汇① 目标：attain genuine sustainability

attain CET-6
/əˈteɪn/ v.
at朝向
tain触碰
「伸手够到」→ 达到、实现（经过努力）
attain a goal / a level / success
The model attained 92% accuracy on the test set.点我该模型在测试集上达到了 92% 的准确率。
Few students attain fluency without daily practice.不每天练习，很少有学生能达到流利的程度。
sustainability CET-6
/səˌsteɪnəˈbɪləti/ n.
sus-(下面)+tain(握住) → 从下面托住
→ 维持 → 可持续性
The machine sustained serious damage in the crash. 僻义sustain = 遭受（损失、伤害）：这台机器在碰撞中严重受损。
genuine CET-4
/ˈdʒenjuɪn/ adj.
真正的；真诚的
genuine leather 真皮
a genuine interest 真心的兴趣
genuine sustainability ✔
✘ greenwashing 有趣词
「漂绿」：只在宣传上装环保。作者用 genuine 暗示：只管生产环节的环保是「表面功夫」。

🧩 词源小陷阱：同一个 tain 同一个来源吗？

con·tainmain·tainob·tainre·tainsus·tain ← tenere 握住 ✋
at·tain ← tangere 触碰 👆（和 tangent、tangible 是亲戚）

长得一样的片段不一定同源 —— 拆词之后，还要结合词源与语境来理解。

✍ 选一选：attain 还是 obtain？

① She finally ____ her goal of becoming a geologist.
② We must ____ permission before sampling in the reserve.
attain = 努力达到（目标、水平）；obtain = 获得（信息、许可、样品）

03核心词汇② 范围：transcend 往外跨，encompass 全圈住

transcend
CET-6/trænˈsend/ v.
trans跨越
(s)cend攀爬
「翻越过去」→ 超出、超越（某种界限）
The problem transcends disciplinary boundaries.点我这个问题超越了学科界限。
Her performance transcended all expectations.她的表现远远超出了所有人的预期。
π is a transcendental number. 彩蛋π 是一个「超越数」——数学里也有 transcend！
encompass
CET-6/ɪnˈkʌmpəs/ v.
en使在内
compass圆规·范围
「用圆规画个圈，把它围进来」→ 包含、涵盖
Our study encompasses geology, geochemistry and machine learning.我们的研究涵盖地质学、地球化学和机器学习。
The approach encompasses the entire value chain.这种方法涵盖了整个价值链。（课文原句改写）
分工：第1句 transcending 生产环节（往外走）→ 第2句 encompasses 整条价值链（全部圈进来）

03核心词汇③ 起点与终点：extraction → disposal

extraction
CET-6/ɪkˈstrækʃn/ n.
ex向外
tract拉
ion名词
「往外拉出来」→ 开采、提取、拔除
同根词：tractor 拖拉机attract 吸引distract 分心abstract 抽象contract 合同
disposal
CET-6/dɪˈspəʊzl/ n.
dis分开
pos放
al名词
「放到一边去」→ 处置、处理
waste disposal 废物处理 · end-of-life disposal 报废处置 · dispose of sth · disposable 一次性的
All the drill-core data are at your disposal. 僻义at sb's disposal = 供某人随意使用：所有岩芯数据任你使用。
Man proposes, God disposes. 谚语谋事在人，成事在天。（dispose = 决定、安排）
😉 矿床 = ore de·pos·it：同一个 pos「放」——大自然把矿「放下」了。
矿产的 extraction
岩石 ⛰ → 矿石 → 精矿 → 金属
从石头里把有价值的物质拉出来
AI 的 feature extraction
遥感 / 化探数据 📊 → 特征 → 成矿预测
从数据里把有价值的信息拉出来

03核心词汇④ 方法：optimize · simulate

optimize
CET-6/ˈɒptɪmaɪz/ v.
optim最好的
ize使…
「使……达到最好」→ 优化；optimum 最佳值 · optimal 最优的 · optimization 优化
⚠ 说「优化」之前必须先问：优化什么？
课文答案：optimizing sustainability performance
（伏笔：AI 里叫「目标函数 / 损失函数」）
simulate
CET-6/ˈsɪmjuleɪt/ v.
simulate 模拟（similis 相似）vs stimulate 刺激（stimulus 刺棒）
He simulated interest in the lecture. 僻义simulate = 假装：他假装对讲座很感兴趣。（希望大家不是 🙃）
performance
CET-4
表演 🎭 →（东西「表演」得怎么样）→ 表现、性能、成效
sustainability performance 可持续性表现engine performance 发动机性能model performance 模型性能
downtime
专业词
停机时间：机器不能工作的时间（machine downtime）
口语：放空、休息的时间 —— I need some downtime after the exam.

05揭晓：我们刚才的读法 ≈ 大模型的读法

Tokenizer：先把文本切成 token，每个片段对应一个编号。
Attention：点击一个片段作为 Query，每个 token ID 都会单独获得一个权重，再「加权求和」得到新表示 —— 就像我们找「谁和谁有关系」。
⚠ 边界：这里是教学用的「伪」tokenizer 和示意权重。真实 token 不一定是完整的词或词根（按频率切）；模型关注的关系也远不止语法，而且是从海量数据中学出来的。
